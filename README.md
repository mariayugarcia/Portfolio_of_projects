### 🧠 1. NLP & Machine Learning

#### 📊 [Predictive Modeling & Sentiment Analysis in Contemporary Best-Selling Sagas](https://github.com)
*   **Description:** An empirical data study investigating emotional valence and narrative resilience in modern *romantasy* blockbusters versus classic genre benchmarks. 
*   **Technologies:** R, `unnest_tokens`, `sentimentr`, `glmnet` (LASSO Regression), TF-IDF matrices, lexicons (NRC, AFINN, Bing).
*   **Key Deliverable:** Developed a custom supervised text classifier to bypass generic sentiment bias, mapping out a high-resolution, multi-year narrative profile tracking customer/reader emotional engagement.

#### 🗺️ [Topic Modeling & Structural Ingestion: Standard LDA vs. Seeded LDA](https://github.com)
*   **Description:** Advanced text engineering pipeline designed to uncover latent thematic structures within high-density narrative universes.
*   **Technologies:** R, `quanteda`, `seededlda` (Gibbs sampling), `regex`, UMass Coherence metrics.
*   **Key Deliverable:** Built a robust data cleaning pipeline using regex for custom chapter chunking. Evaluated unsupervised Latent Dirichlet Allocation (LDA) against a semi-supervised Seeded LDA guided by a domain-specific dictionary to isolate clean, non-overlapping thematic dimensions.
